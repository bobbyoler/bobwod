☁️ Cloud Sync

Paste your Firebase config to enable cross-device sync. Your data is stored privately under your Google account.

How to get your Firebase config →
  1. Go to console.firebase.google.com
  2. Click Add project → name it "Bobwod" → create
  3. Click </> Web to add a web app → name it "Bobwod" → Register
  4. Copy the firebaseConfig object and paste it above
  5. In the left sidebar → Build → Firestore Database → Create database → Start in test mode
  6. In the left sidebar → Build → Authentication → Get started → Google → Enable → Save
